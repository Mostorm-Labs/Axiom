vertical slice. Task 19 supersedes that host architecture with fixed Base

The arm64 macOS preset now builds the real AppKit/CAMetalLayer host against
locked vcpkg Skia 148 with the Metal and PNG features. MetalHost creates one
Ganesh Metal context, wraps each drawable texture as a backend render target,
scales the shared canvas for Retina coordinates, draws Base, Annotation, and
Chrome through SkiaRenderer, flushes/submits, and presents on the same Metal
command queue. Rendering remains event-driven through AppKit invalidation.

Local dependency-bootstrap qualification:

Google's official CIPD host was unreachable from this workstation. The local
configure therefore used a host-only vcpkg-tool-gn overlay packaging GN 2486,
built and self-tested from the read-only ArthurSonzogni/gn GitHub mirror at
commit 641ace93dd9560e75e7add0d08f77b446fbb3b78. Canvas source and CI were not
changed to use that overlay. Direct GitHub full-index patch downloads for fmt
and spdlog were also unreachable; their commit patches were recovered through
the GitHub API, expanded with the exact parent/current blob ids, and accepted
only after their SHA-512 values exactly matched the locked vcpkg portfiles.
Skia's piex and wuffs external archives likewise came from commit-identical
reachable GitHub mirrors and were hash-verified before the successful build.
This proves the locked source inputs compile locally, but it is not a claim
that the official CIPD artifact itself was exercised.
