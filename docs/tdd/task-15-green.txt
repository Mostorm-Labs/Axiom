Task 15 green phase (updated 2026-07-25)

Implemented a version 1 authenticated JSONL control protocol with strict
launcher-command and native-event direction allowlists. The protocol rejects
raw pointer, stroke, and video-frame messages; bounds inbound JSONL lines by
bytes; bounds outbound JSON by byte, depth, and node budgets; enforces a
256-UTF-8-byte request-ID limit; and requires an authenticated hello before a
client session accepts commands.

Added the Windows named-pipe server with a current-user/SYSTEM ACL, local-only
single-instance pipe, overlapped cancellation, bounded read/write queues, and
connection generations so a response from a disconnected client cannot cross
into a replacement connection. The pipe thread only queues commands; Document,
D3D, DComp, and WebView work is drained on the window UI thread.

Wired native startup, authenticated readiness, synchronous HRESULT/render
rollback transactions for create/open/set-bounds/delete commands, checked
WebView2 setters, fatal shutdown, startup --open surface restoration, and
bounded IPC queue draining.
Added a locked Electron harness with context isolation, sandboxing, no renderer
access to the session token, bounded framing/backpressure, reconnect attempts,
and a three-second graceful native shutdown window.
