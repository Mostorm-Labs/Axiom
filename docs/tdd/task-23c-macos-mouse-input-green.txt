Task 23C macOS AppKit mouse drawing GREEN evidence
Date: 2026-08-03 (Asia/Shanghai)

Implemented scope:
  The private overlay-only CanvasPointerMetalView now converts AppKit left-
  mouse down/drag/up events synchronously into logical-point RawMacMouseEvent
  values and owns one MacosMouseSession. Its weak delegate sends the fixed
  session output to CanvasCompositionView on the AppKit main thread.

  CanvasCompositionView keeps setCanvasDocument as the read-only path and adds
  setEditableCanvasDocument for a mutable Document-backed
  MacosWhiteboardInput. Accepted input mutates the Document through that
  controller and invalidates only the Base Metal view for blank-canvas ink or
  only the Overlay Metal view for parent-normalized embedded annotations. It
  does not call setCanvasDocument per point.

  Active input is cancelled through the idempotent session before interaction
  gating, editable/read-only document replacement, view/window teardown, and
  app/window loss of activity. Notification blocks capture the pointer view
  weakly, the composition delegate is weak, and all integration entry points
  enforce or inherit AppKit main-thread affinity. main.mm opts into the editable
  setter.
