Task 21 macOS WKWebView navigation — GREEN implementation checkpoint
====================================================================

Date: 2026-08-01 (Asia/Shanghai)
Branch: codex/macos-platform

This increment keeps the RED audit in `task-21-macos-wkwebview-navigation-red.txt`
and adds the smallest native navigation lifecycle. `WKWebViewSurface` now has a
private weak-delegate bridge, a fail-closed navigation policy, and a latest-wins
initial-load tracker. Production URLs are restricted to absolute HTTPS and a
canonical packaged `file:` root; bounded `data:text/html` is available only
when `Options::allowTestDataUrls` is explicitly enabled. Both navigation action
and response policy callbacks apply the same policy, including redirects and
main-frame checks.

Safety invariants
-----------------

* All public methods and delegate callbacks require the AppKit main thread.
* A lifetime epoch invalidates callbacks on close; a separate navigation epoch
  rejects stale re-entrant `loadRequest` returns.
* Delegate closures hold only a `std::weak_ptr<Impl>` and the WebKit delegate
  property remains weak; close clears the token and calls `stopLoading`.
* At most one generation is issued. New requests replace the deferred URI and
  stop the active load; only the latest terminal event can complete the initial
  load, exactly once. Completion callbacks are moved before invocation and
  exceptions are contained at the ObjC boundary.
