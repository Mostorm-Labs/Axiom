Task 14 green phase (updated 2026-07-24)

Implemented the version 1 canonical JSON schema with MessagePack file
encoding, strict finite/type/parent-graph validation, and semantic retention of
representable fields for unknown node types. Values that canonical JSON or
MessagePack cannot preserve losslessly (including out-of-range JSON integers,
binary values, non-finite numbers, and invalid UTF-8) are rejected.

The codec validates live models before encoding and applies explicit budgets
for nodes, stroke points, strings, retained unknown nodes, parent depth, input
nesting, and the 512 MiB encoded size. JSON integers are checked lexically
before DOM parsing. MessagePack is structurally preflighted with an iterative
stack, so excessive nesting cannot overflow nlohmann's recursive binary
reader. Parent graphs are checked iteratively and decoded nodes are installed
with one atomic linear-time bulk replacement; corrupt input never partially
replaces the live Document.

Added the Win32 atomic DocumentStore, a shared 512 MiB save/load boundary,
and explicit --open/--save/--self-test-document wiring. Saves write and flush
<path>.tmp before MoveFileExW replacement. Restored Video nodes always
navigate to the packaged video adapter and receive an approved remote or local
source through the versioned host bridge; process-local media mappings are not
trusted after restart. Embedded surfaces and their ParentNormalized annotation
strokes are recreated from the decoded document.
