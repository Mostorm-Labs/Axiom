Implemented scope:
  - findTopmostStrokeHit is a read-only, noexcept, platform-neutral query in
    world/top-left logical coordinates. Its result is Hit, NoHit,
    InvalidQuery, or BudgetExhausted and carries no NodeId or Node copy.
  - A Hit returns only the current node index, cache identity, and layer. The
    caller must validate index plus cache identity again before any later
    mutation.
  - Visual priority is deterministic: Annotation nodes are scanned in reverse
    document order before Base nodes are scanned in reverse document order.
    Only a StrokeNode in the expected layer and coordinate space is eligible;
    Embedded and Chrome layers plus EmbeddedNode and UnknownNode payloads are
    never returned.
  - Base/World strokes use a finite-bounds broad phase followed by capsule
    distance against the eraser sweep. One-point strokes use point-to-sweep
    distance. Multi-point strokes first use a fixed-capacity exact orientation
    predicate for closed-segment intersection, then the four endpoint-to-
    segment distances when disjoint. This avoids determinant cancellation and
    tiny-interior-parameter clamping while covering degenerate sweeps and
    duplicate-point segments. The threshold is eraser radius plus the stroke's
    true half-width.
  - Parent-normalized Annotation geometry is mapped point by point through the
    current Embedded parent bounds, and relative width is resolved through the
    current minimum parent extent. The world point and width use the renderer's
    actual float expression order and validate the rounded float result before
    distance math. This accepts finite FLT_MAX results even when the exact real
    product lies just beyond FLT_MAX, while still rejecting float overflow. A
    positive stored width that rounds to +0 after parent resolution matches
    Skia's visible hairline semantics: it contributes zero half-width but its
    centerline remains hittable by an exact or positive-radius eraser sweep.
    No throwing embedded-transform helper and no stale child/parent-only broad
    phase is used, so moved, anisotropic, large-origin, and out-of-parent
    geometry remains correct.
  - Query points and radii, node/parent bounds, stored widths, stroke points,
    and mapped coordinates are validated fail-closed: inputs must be finite,
    bounds and stored widths must be strictly positive, and resolved float
    geometry must remain finite. Only the renderer-valid resolved hairline
    width may be zero. Double distance intermediates keep valid extreme float
    sweeps from overflowing distance math.
  - One explicit WorkCounter covers every reverse document-node visit, every
    parent lookup candidate, and every inspected point/segment primitive.
    Parent lookup is implemented directly under that counter rather than via
    an uncounted Document::find. Exhaustion at any point returns no token, even
    when an earlier segment in the partially inspected candidate intersected.
    A zero budget is NoHit for an empty document but BudgetExhausted as soon as
    a non-empty document requires its first visit.
  - The production source contains no dynamic container, heap construction,
    exception, IPC/Electron, Skia, or platform dependency. The source contract
    rejects common allocating containers, heap APIs/helpers, platform and IPC
    tokens, and the unit test statically verifies the public query is noexcept;
    manual line-by-line review covers the broader allocation-free claim.
