    -P tests/scripts/webview2_initial_load_fail_contract_test.cmake

Result: failed as intended with "Impl::fail must normalize into local

GREEN contract

  cmake -DSURFACE_SOURCE=src/platform/windows/webview2_surface.cpp \
    -P tests/scripts/webview2_initial_load_fail_contract_test.cmake

Result: passed. The narrow contract extracts only Impl::fail and requires, in
order, a local normalized failure, shared_from_this retention, completion

explicitly rejects return lastResult after callback dispatch.

The same green command is registered as
canvas_webview2_initial_load_fail_source_contract in tests/CMakeLists.txt so it
runs on ordinary non-Windows and Windows CTest hosts.
