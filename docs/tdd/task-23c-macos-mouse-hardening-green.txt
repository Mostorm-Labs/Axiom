Production fixes:
  - MacosWhiteboardInputResult::fullRedraw now takes precedence over its
    optional layer, so Base and Overlay are both invalidated before returning.
  - CanvasPointerMetalView can atomically take its one cancellation output.
    Composition teardown clears the weak delegate, takes that output, and
    consumes it directly through the still-live controller. If session and
    controller state are unexpectedly out of sync, setMode(Interact) rolls
    back any remaining active controller preview. Teardown deliberately drops
    redraw results: scheduling Metal work while the view is destructing has no
    value and would add re-entrancy risk. Taking the session output also makes
    later pointer-view teardown cancellation an idempotent no-op.
  - Hosted macOS CI retains the aggregate GUI discovery check and additionally
    discovers each of AppKit scheduling, composition, mouse input, and
    WKWebView suites independently before running GUI tests.
