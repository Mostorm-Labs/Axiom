Implemented scope:
  - MacosTabletPointerBridge converts only a validated Pen sample whose intent
    is Ink. EraserPending, Cursor, Unknown, intent mismatches, invalid device or
    pointer identity, non-finite positions, and invalid supported-pressure
    values fail closed without producing PointerSample output.
  - The bridge uses fixed arrays and preserves the order of eligible session
    outputs. It introduces no dynamic container, heap allocation, IPC, or
    Electron call in the tablet hot path.
  - A device that advertises Pressure must supply a finite normalized value.
    A device without that capability always receives neutral pressure 0.5,
    regardless of the raw field. Apple's scaled tilt remains in the original
    MacosTabletSample; PointerSample degree tilt is explicitly zero/unknown
    rather than mislabelling scaled values as degrees.
  - MacosWhiteboardInput accepts only Mouse and Pen, continues to reject Touch,
    unsupported kinds, and predicted input, and records the active pointer
    kind so a same-id cross-modality sample cannot move or commit a stroke.
    The shared InputRouter and Windows behavior are unchanged.
  - Pen still takes the router's annotation-first path, but the macOS
    controller explicitly permits Pen Down only in Draw mode. Pen in Select or
    Interact fails closed before document mutation; ordinary Mouse behavior
    remains opt-in and unchanged.
  - CanvasPointerMetalView synchronously dispatches eligible associated and
    native tablet point output, proximity-leave output, and reset output in
    session order. Exact native/associated deduplication cannot create two
    strokes, and the controller permits only one live pointer stroke.
  - App/window resign, window close, detach, mode/document/read-only
    replacement, ordinary-mouse switching, explicit cancellation, and
    composition deallocation roll back an active Pen preview exactly once.
    Composition teardown clears the weak delegate first and consumes the
    cancellation directly without scheduling a Metal frame during destruction.
  - Existing layer-specific invalidation remains in place, so accepted Pen
    samples use the same PointerSample -> MacosWhiteboardInput -> Document ->
    Metal presentation path as visible ordinary-mouse ink.

Pure integration coverage:
  - Associated/native exact deduplication commits one Base stroke with all
    ordered pressure samples.
  - Draw-mode Pen over an embedded surface commits parent-normalized
    Annotation geometry.
  - EraserPending, Cursor, and Unknown never mutate Document.
  - Interact-mode Pen reaches the controller seam but is rejected without
    changing Document; this is not a WKWebView runtime claim.
  - Proximity leave and reset each cancel a live preview once, with repeated
    cancellation idempotent.
  - A second tablet contact is ignored and cannot cross-commit the first
    active stroke.
