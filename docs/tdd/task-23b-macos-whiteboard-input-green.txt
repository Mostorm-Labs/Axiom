Task 23B macOS whiteboard input controller GREEN evidence
Date: 2026-08-03 (Asia/Shanghai)

Implemented scope:
  * InputRouter has an explicit mouse-draw opt-in. It defaults to false, so
    existing Windows routing is unchanged; an enabled Mouse routes to drawing
    only while the mode is Draw.
  * MacosWhiteboardInput is a pure C++ controller with an explicit serialized,
    future-AppKit-main-thread ownership contract and no internal locking or UI
    framework dependency.
  * It owns the mutable Document reference, InputRouter, and one active
    StrokeBuilder. Only non-zero-id, finite, real Mouse samples with pressure
    in [0, 1] are accepted; orphan, duplicate, mismatched, predicted,
    non-Mouse, and invalid samples do not mutate the document.
  * Down reverse-scans document order for the topmost Embedded hit. It creates
    a collision-free Base or Annotation preview with both builder and preview
    point storage reserved for 512 points.
  * Move uses the append-only Document path and returns a layer-specific dirty
    rectangle. The normal reserved hot path does not copy Document and creates
    no temporary strings or containers.
  * Up supports a single-point stroke, finalizes Base strokes in world space,
    and converts an Annotation to parent-normalized coordinates only after
    revalidating its Embedded parent.
  * Cancel, mode changes, and document replacement erase an active preview
    exactly once before clearing state. Logical append, parent-transform, or
    externally missing-preview failures also clear state and leave no preview.
    A null replacement fails without cancelling or replacing current state.
  * Preview ownership is guarded by the cache identity captured after add plus
    controller-owned revision and non-append revision counters. Each accepted
    append advances the expected revision, and Up revalidates immediately
    before final mutation. Cleanup erases only the matching cache identity;
    an erase-plus-recreate node with the same id is preserved and returns a
    Failed result with a safe full redraw request.
  * Result values are fixed: kind, optional layer, optional dirty bounds, and
    fullRedraw. A real document replacement requests full redraw.
  * The direct-source/CMake contract includes the controller, rejects native
    UI/IPC/web/Windows dependencies from compiled seam code, requires the
    macOS target to compile it, and excludes it from Windows direct sources.

Known performance debt:
  StrokeBuilder and the live Document preview intentionally keep parallel
  point vectors. Both reserve the first 512 points, but longer strokes can
  grow both vectors and Up still copies committed points into the final
  StrokeNode. Measure long-stroke behavior before redesigning that ownership;
  this review fix does not claim to remove the >512-point allocation cost.
