Task 23A macOS pointer seam GREEN evidence
Date: 2026-08-03 (Asia/Shanghai)

Implemented scope:
  * RawMacMouseEvent is a pure C++ value type; no AppKit object is retained.
  * MacosPointerAdapter converts flipped or unflipped view-local coordinates
    with non-zero bounds into top-left Canvas logical points. backingScale is
    deliberately not applied and out-of-bounds positions are not clamped.
  * Seconds convert to microseconds with negative/NaN input mapped to zero and
    positive overflow saturated at uint64 max.
  * Missing or non-finite pressure defaults to 0.5; finite pressure is clamped
    to [0, 1]. Mouse kind, zero tilt, non-predicted samples, and all four phases
    are explicit.
  * MacosMouseSession owns one left-button stroke at a time. IDs are non-zero
    and monotonically increasing, Move/Up reuse the active ID, Up clears it,
    and orphan events are ignored.
  * Duplicate Down emits old Cancel followed by a new Down in a fixed two-slot
    result (no per-event heap allocation). Lifecycle cancel reuses the last
    valid sample exactly once. Raw Cancel is fail-safe and terminates an active
    session even if its button metadata differs.
  * The platform-neutral source contract rejects AppKit/NSEvent, IPC/JSON,
    Electron/WebKit, named-pipe, and Windows-header dependencies and verifies
    that Windows platform sources/target do not reference this seam.
